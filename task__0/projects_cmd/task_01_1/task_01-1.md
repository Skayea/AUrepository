# Основные сведения о **CMD** (Command Prompt)

## **Справка**
- Вывести список доступных внутренних команд с кратким описанием
```cmd
help
```
- Получить детальную информацию о синтаксисе и параметрах конкретной команды
**[команда] /?**
```cmd
cd /?
```
# Внешний вид CMD в Windows
- обычный запуск:
Открывается в папке текущего пользователя **C:\Users\\[Имя пользователя]**
- Запуск от имени администратора:
Открывается в системной папке **C:\Windows\System32**
